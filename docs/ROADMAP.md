# Implementation roadmap

[Repository overview](../README.md) · [Evaluation guide](EVALUATION.md)

This page records scope, not delivery dates or a promise of competition placement.

## Implemented and locally verified

- Real FalkorDB knowledge/state storage and graph-copy rehearsal.
- Parameterized accepted-fact selection across partner and two timestamps.
- Deterministic assessment, scoped runbook conflict, and missing-evidence handling.
- Optional Gemini tool loop with response-shape and source-ID validation.
- Source inspection, temporal views, graph expansion, saved receipts, and stale-action rejection.
- Downloadable repair drafts and idempotent in-app approval.
- Synthetic migration/proposal/withdrawal replay and disposable-graph integration checks.

## Next product priorities

| Priority | Work | Acceptance evidence |
| --- | --- | --- |
| 1 | Real source import | A reviewer supplies a new document/export; accepted extracted facts retain provenance and change a supported investigation without editing fixture code. |
| 2 | Evidence-backed expertise discovery | Reviewer suggestions cite relevant contributions and ownership; they do not equate centrality with competence. |
| 3 | Incremental updates | A new source version updates affected facts, exposes scoped disagreement, and invalidates dependent results with clear history. |
| 4 | Broader evaluation | Varied fixtures, ambiguous identities, missing evidence, and agent explanations are evaluated with recorded failure cases. |
| 5 | Deployment and submission media | A working deployment strategy or fully reproducible local demo, a polished video, and verified submission-panel requirements. |

## Later extensions

Live app connectors, versioned ownership/topology, source permissions, explicit publishing approval, transactional ingestion, cross-process coordination, MCP packaging, and multiple cooperating agents. Each needs its own working demonstration and failure handling before it is listed as a capability.

## Submission state

The repository contains a working local prototype and evaluation instructions. A hosted application, final demo video, general ingestion, and the authenticated organizer submission are not completed by this repository-polish milestone.
